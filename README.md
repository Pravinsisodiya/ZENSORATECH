# ZENSORATECH

This repository contains the tasks completed for the ZENSORATECH internship assignment.

## 📌 Project Overview
A responsive navigation bar built using HTML, CSS, and JavaScript.  
The design works on both desktop and mobile devices.

## 🚀 Features
- Semantic HTML5 structure
- Responsive design using CSS Flexbox
- Mobile hamburger menu
- JavaScript toggle functionality
- Hover effects on navigation links

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
